**Santinhos de Montar** — *+100 santos pra criança recortar, montar e brincar, longe da tela.* Nome checado: nenhum produto usa (2026-09-11).

- Origem: concorrente "Dobraduras Bíblicas / BiblinhaPlay" (Casa Seth) escalado ~20 dias a R$9,90 — 125 personagens bíblicos em paper toy + bônus Presépio/Ressurreição/Armadura. Força dele = marca Biblinha (500 mil, não copiável) + "amassou? imprime de novo". É EVANGÉLICO: nenhum santo → buraco estrutural pro católico. Busca não achou paper toy de santos no BR.
- Conteúdo: santos populares BR (Aparecida, Santo Antônio, São Francisco, São Jorge, Santa Rita, São José, Padre Pio, Santa Teresinha, Carlo Acutis — canonizado 2025, "santo do videogame" = gancho longe da tela) + plaquinha com dia da festa + versão colorir.
- Preço: Básico R$12,90 (50) / **Completo R$19,90** (100 + colorir + Capelinha Aparecida) / exit R$14,90. Bumps: Igrejinha pra brincar de missa, Presépio de Montar, Via Sacra de Montar (R$9,90 cada) + combo R$19,90. Upsell Licença Catequese R$27. AOV estimado R$28–32. Se CPA alto, baixar Completo pra R$14,90 antes de mexer no criativo.
- Timing: mini oferta "Nossa Senhora Aparecida de Montar" R$9,90 pro 12/out (Aparecida + Dia das Crianças no mesmo dia); oferta cheia em novembro com Presépio pro Natal. Eleição 4/out/2026: "santinho" = panfleto político e CPM caro até lá.

- Template do molde PRONTO (2026-09-11): Desktop\PROJETOS\santinhos-de-montar\template\build.py — recorta artes de uma imagem do ChatGPT, desenha planificação exata em mm (cabeça cubo 4 cm, corpo caixa 4×2,5×5,5 cm, 7 abas cada, dobra/corte automáticos) e gera HTML + PDF A4 + preview via Edge headless. Folha 001 Aparecida gerada. ChatGPT sozinho erra a geometria (lados desiguais, faltou costas) → IA só faz ARTE, molde vem do template. Visual aprovado: azul/dourado, cabeçalho em arco, borda de renda (diferente do Biblinha amarelo/roxo).
